# Niro AI frontend

Vue 3 + TypeScript dashboard for dependency manifest analysis.

For complete backend and frontend setup, configuration, API documentation, tests, model notes and troubleshooting, see the [project README](../README.md).

## Local commands

```bash
npm install
cp .env.example .env
npm run dev
```

The development server runs at `http://localhost:5173` and proxies `/api` to `http://127.0.0.1:5000`.

```bash
npm run type-check
npm run build
npm run preview
```
